# Bio-Metric Activity Logger (CLI)

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Domain: Fitness](https://img.shields.io/badge/Domain-Fitness-orange?style=for-the-badge)

A command-line fitness tracking application engineered to record running sessions, calculate biometric performance metrics, and maintain structured activity logs.

## Overview

The Bio-Metric Activity Logger provides runners with a lightweight console interface to log distance, duration, and pace. It processes raw workout telemetry to derive speed analytics and historical performance trends while maintaining local activity records.

## Key Features

- **Pace & Velocity Calculations**: Automatically evaluates running pace and average speed from logged distance and elapsed time inputs.
- **Activity History Tracking**: Maintains persistent records of workouts and running sessions for audit and historical review.
- **Performance Analytics**: Aggregates workout data over time to present structured progress reports in the terminal.
- **Lightweight Console Interface**: Responsive terminal workflow designed for quick metric logging without external GUI or browser overhead.

## Technology Stack

- **Language**: Python
- **Interface**: Command-Line Interface (CLI)
